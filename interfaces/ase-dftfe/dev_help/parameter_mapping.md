# ASE-DFTFE Parameter Mapping

This document details the mapping between the ASE Calculator parameters (`dftfe.py`), the JSON payload sent over the socket, and the corresponding `parameterFile.prm` entries generated by the C++ wrapper.

## Core Parameters

| ASE Parameter (`dftfe.py`) | JSON Key | parameterFile.prm Setting | Description |
| -------------------------- | -------- | ------------------------- | ----------- |
| `xc` | `xc` | `set EXCHANGE CORRELATION TYPE` | Exchange-correlation functional (e.g., "GGA-PBE") |
| `polynomial_order` | `polynomial_order` | `set POLYNOMIAL ORDER` | FE polynomial order (default: 7) |
| `tolerance` | `tolerance` | `set TOLERANCE` | SCF convergence tolerance |
| `fermi_temp` | `fermi_temp` | `set TEMPERATURE` | Fermi-Dirac smearing temperature (Kelvin) |
| `scf_mixing` | `scf_mixing` | `set MIXING PARAMETER` | SCF mixing parameter (Default: 0.2 for Anderson, 0.5 otherwise) |
| `mixing_scheme` | `mixing_scheme` | `set MIXING METHOD` | Mixing scheme (e.g., "Anderson", "Pulay", "Broyden") |

## Parallelization

| ASE Parameter | JSON Key | parameterFile.prm Setting | Description |
| ------------- | -------- | ------------------------- | ----------- |
| `npkpt` | `npkpt` | `set NUMBER OF K-POINTS` | Number of k-points to parallelize over |
| `npw` | `npw` | `set NUMBER OF PLANE WAVES` | Number of plane waves to parallelize over |

## Mesh & Geometry

| ASE Parameter | JSON Key | parameterFile.prm Setting | Description |
| ------------- | -------- | ------------------------- | ----------- |
| `mesh_size` | `mesh_size` | `set MESH SIZE AROUND ATOM` | Finite element mesh size around atoms |
| `atom_ball_radius` | `atom_ball_radius` | `set ATOM BALL RADIUS` | Radius of the atomic sphere for meshing |
| `mp_grid` | `mp_grid` | `set SAMPLING POINTS {1,2,3}` | Monkhorst-Pack k-point grid |
| `mp_grid_shift` | `mp_grid_shift` | `set SAMPLING SHIFT {1,2,3}` | K-point grid shift |

## SCF & Solver Control

| ASE Parameter | JSON Key | parameterFile.prm Setting | Description |
| ------------- | -------- | ------------------------- | ----------- |
| `max_scf_iterations` | `max_scf_iterations` | `set MAXIMUM ITERATIONS` | Maximum number of SCF iterations |
| `mixing_history` | `mixing_history` | `set LBFGS HISTORY` | History size for mixing/Anderson acceleration |
| `num_kohn_sham` | `num_kohn_sham` | `set NUMBER OF KOHN-SHAM WAVEFUNCTIONS` | Number of KS states to compute |
| `orthogonalization_type` | `orthogonalization_type` | `set ORTHOGONALIZATION TYPE` | Method: "Auto", "CGS", etc. |
| `smeared_nuclear_charges` | `smeared_nuclear_charges`| `set SMEARED NUCLEAR CHARGES` | "true"/"false" |
| (derived from properties) | `compute_stress` | `set CELL STRESS` | Compute cell stress (enabled if 'stress' in properties). NOTE: Controlled via runtime flag in socket interface, corresponding to `Optimization` subsection. |
